Hands-on networking and security labs from the Cyber Shujaa Cloud and Network Security track, plus HackTheBox Academy and TryHackMe modules. New entries added weekly.

---

### [Build a Switch and Router Network](/labs/build-a-switch-and-router-network/)
Cabling and configuring a switch, router, and two PCs from scratch — IPv4/IPv6 addressing, encrypted passwords, and interface verification with Cisco IOS.

### [Using Wireshark to Examine Network Traffic](/labs/wireshark-icmp-traffic/)
Capturing local and remote ICMP traffic to see exactly when — and why — ARP resolves a MAC address, and when it doesn't.

### [Investigating the TCP/IP and OSI Models in Packet Tracer](/labs/tcp-ip-osi-models/)
Tracing a single HTTP request frame-by-frame through Packet Tracer's Simulation mode to watch encapsulation and de-encapsulation happen live.

### [TryHackMe: DNS in Detail](/labs/tryhackme-dns-in-detail/)
Working through DNS record types, the resolution hierarchy, and live `nslookup` queries against a practice domain.

### [HTB Academy: Network Traffic Analysis](/labs/htb-network-traffic-analysis/)
tcpdump and Wireshark from fundamentals to a live capture — extracting a file over FTP and recovering plaintext credentials from HTTP traffic.

### [HTB Academy: Web Requests](/labs/htb-web-requests/)
HTTP fundamentals, headers, Basic Auth, and full CRUD against a REST API — via cURL, DevTools, and the browser Console.
